# Named Entity Recognition (NER) Models

This repository contains two Named Entity Recognition (NER) models for natural language processing tasks.

## BERT-Based NER Model

This model uses the BERT (Bidirectional Encoder Representations from Transformers) architecture for Named Entity Recognition.

### Model Details
- **Model Used:** BERT
- **Description:** This NER model is fine-tuned on a dataset to identify entities in text using the BERT architecture.
- **Training Process:** Includes preprocessing of text, tokenization, and fine-tuning of the BERT model.

## Luong Attention-Based NER Model

This model employs the Luong attention mechanism for Named Entity Recognition.

### Model Details
- **Attention Mechanism:** Luong Attention
- **Description:** This NER model utilizes the Luong attention mechanism to enhance the identification of entities in text.
